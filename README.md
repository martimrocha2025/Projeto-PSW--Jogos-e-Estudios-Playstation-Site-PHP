Projeto para a Cadeira de PSW onde foi criado um site para Jogos e Estúdios Playstation através do PHP Laravel.

Está a ser usada uma base de dados MySQL através do MySQL Workbench, onde são guardados os dados que são introduzidos no site.

O intuito foi testar a minha capacidade de criar um site com PHP Laravel com diferentes tipos de utilizadores com permissões variadas.
